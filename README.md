# Sistema de Gestión de Recursos Humanos (CRUD)

Aplicación Full Stack orientada a la gestión y administración de empleados/recursos humanos. Permite realizar las operaciones fundamentales de un CRUD (Crear, Leer, Actualizar y Eliminar) conectando un cliente dinámico en React con un backend en Spring Boot.

---

## 🛠️ Tecnologías Utilizadas

### **Backend**
* **Lenguaje:** Java
* **Framework:** Spring Boot
* **Persistencia / ORM:** Spring Data JPA / Hibernate
* **Base de Datos:** MySQL
* **Gestor de Dependencias:** Maven

### **Frontend**
* **Librería UI:** React
* **Lenguaje:** JavaScript / TypeScript
* **Librería HTTP:** Axios / Fetch API (para comunicación con la API REST)
* **Estilos:** Bootstrap / Tailwind CSS / CSS Modules

---

## 🚀 Funcionalidades Principales

* 📋 **Listar Personal:** Visualización fluida de los registros de empleados recuperados desde la API.
* ➕ **Registrar Empleado:** Formulario para alta de nuevo personal.
* ✏️ **Actualizar Información:** Edición de datos existentes en tiempo real.
* 🗑️ **Eliminar Registro:** Borrado dinámico de empleados en base de datos.
